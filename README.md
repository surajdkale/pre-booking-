# Shree Swami Samarth Tours & Travels – Pre-Booking Page

A single-page booking form. Customers fill in trip details and tap a button;
WhatsApp opens with the message ready to send to +91 98604 80613.

## Files
- `index.html` – the whole website (no build step, no other files needed)
- `.nojekyll` – tells GitHub Pages to serve the files as they are

## Publish with GitHub Pages
1. Settings -> Pages
2. Source: Deploy from a branch
3. Branch: main, folder: / (root), then Save
4. Site link: https://YOUR-USERNAME.github.io/REPOSITORY-NAME

## Edit later
Open `index.html` on GitHub, tap the pencil icon, change text or prices, then Commit changes.
The WhatsApp number is in the script near `var NUMBER = "919860480613";`
